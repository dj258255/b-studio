결정 전에 측정이 필요한 일의 결과를 여기에 남깁니다. 가설이 틀린 결과도 남깁니다. 양식은 [실험 보고서 양식](../templates/experiment-report.md)을 따르고, 파일 이름은 `YYYY-MM-DD-<짧은-이름>.md`로 씁니다.

만든 기능이 실제로 나아졌는지는 같은 과제를 반복 실행해서만 주장합니다. 가설은 실행 전에 이슈에 적고, 성공 비교는 Fisher 정확 검정으로 판정합니다. 과제는 예제(Spring Boot api + Next.js web)의 작은 과제이고, 로컬 Claude Code 구독으로 돌렸습니다. 비용은 청구가 아니라 공식 단가로 환산한 추정치입니다.

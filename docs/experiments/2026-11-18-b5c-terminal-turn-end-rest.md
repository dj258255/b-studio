# 실측: 턴 끝의 나머지를 코어로 옮긴 뒤 통과와 소진 (2026-11-18)

[ADR-217](../decisions.md), 이슈 #1291. B5c에서 바꾼 것은 넷입니다.

- 턴 끝의 예외 경로 분류를 Rust 코어로 옮겼습니다.
- 게이트 밖 사유는 코어가 사실을 받아 고르게 했습니다.
- 게이트 전체에 3300초 상한을 두었습니다.
- 플랫폼 실패는 이번 오류가 켜기 실패에서 난 것일 때만 인정합니다.

이 실측은 바뀐 고리를 거쳐도 평소의 턴 끝(통과, 재시도 끝 소진)이 그대로인지 봅니다.

## 환경

- **기기와 CLI**: macOS arm64, 실제 Claude Code CLI 2.1.326(구독 로그인)
- **세션 방식**: 이 컴퓨터 방식 세션 터미널. 실험 스위치를 끈 서버로 띄웠습니다.
- **세션 모델**: `haiku`
- **코드**: 브랜치 `feat/b5c-terminal-turn-end-rest`(350d0a0)
- **서버**: 실측 전용 폴더와 3923번 포트로 띄웠습니다.
- **하네스**: `measure-term.mjs pass`, `measure-term.mjs exhaust`. 프로젝트는 둘 다 vf3입니다.

정리할 때 세션 둘을 멈추고 지웠습니다. 세션 폴더, 컨테이너, 네트워크, 볼륨은 남지 않았습니다.

## 보지 못한 것

- **게이트 시간 상한(3300초)이 실제 세션에서 걸리는 모습**
  - 시험에서는 상한을 700ms로 줄여 흉내 냈습니다.
  - 실제 게이트가 이만큼 도는지는 재지 않았습니다. 설정 상한을 합산한 값만 ADR에 적었습니다.
- **CLI가 Stop 훅을 3600초에 끊는 동작**: 실행 파일 문자열로만 확인했습니다.
- **예외 경로**: 플랫폼 실패와 체크포인트를 남긴 뒤 던지는 경로는 시험으로만 확인했습니다.
- **desk 화면**: 보지 않았습니다.

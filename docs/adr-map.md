# ADR 지도

[설계 결정 기록](decisions.md)에는 ADR이 199개 있습니다. 이 문서는 그중 **무엇이 지금도 유효하고, 무엇을 먼저 읽으면 되는지**를 보여 줍니다. 결정의 내용과 근거는 원문에 있고, 여기는 길잡이만 둡니다.

## 읽는 법

- **조사 기준**: 2026-11-15의 `main`(ADR-199까지)입니다. ADR 원문, 그 뒤 ADR의 덧붙임, 지금 코드(파일이 있는지, 호출하는 곳이 있는지)를 대조해 상태를 정했습니다. 새 ADR이 들어오면 이 지도에도 한 줄을 더합니다.
- **상태**
  - **유효**(86개): 지금 코드와 제품에 그대로 적용됩니다.
  - **유효·덧붙임**(60개): 유효합니다. 다만 원문 끝의 덧붙임이나 뒤 ADR이 내용을 넓히거나 고쳤으니 원문을 끝까지 읽습니다.
  - **일부 바뀜**(22개): 일부가 뒤 결정으로 바뀌었거나, 그 결정의 일부 대상(주로 웹 화면 시절의 HTTP 경로)이 지워졌습니다. 남은 부분은 유효합니다.
  - **대체됨**(3개): 뒤 ADR이 결정을 바꿨습니다. 화살표의 ADR을 읽습니다.
  - **지나감**(28개): 바꾼 ADR은 없지만 대상(웹 화면, 데스크톱 앱, 지운 기능)이 없어졌습니다. 왜 그런 모양이었는지 알고 싶을 때만 읽습니다.
- 웹 화면과 데스크톱 앱은 2026-10-23에 지웠습니다(ADR-186, #917). 웹 화면 시절에만 부르던 API 경로는 2026-11-06에 지웠습니다(#1016·#1022). "지나감"과 "일부 바뀜"의 대부분이 이 두 번의 삭제에서 나왔습니다.
- ADR 원문은 고치거나 지우지 않습니다. 대체됐거나 지나간 ADR은 원문 제목 바로 아래에 "지금 상태" 한 줄을 달았습니다.
